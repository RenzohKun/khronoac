# Demostración de Khronoac

Este conjunto de datos genera un horario académico de ejemplo con 7 asignaturas, 5 docentes, 2 aulas y 2 laboratorios. Con un mínimo de 20 estudiantes por paralelo, el resultado contiene 14 paralelos y 42 sesiones distribuidas de lunes a viernes, sin cruces de docentes, espacios ni paralelos.

Los JSON están dentro de `khronoac_datos/` con el mismo formato que usa la aplicación. Para abrir este ejemplo en una copia de Khronoac, respalda primero sus datos actuales y luego reemplaza los cuatro archivos de su carpeta `khronoac_datos/` por los de este directorio.
