# Khronoac

Khronoac es un programa orientado a la optimización y automatización en la creación de horarios académicos. Este programa abarcara desde la estimación de la demanda estudiantil y la proyección de paralelos, hasta la asignación optima de docentes, asignaturas, aulas y franjas horarias, reduciendo el margen de error humano y optimizando el tiempo de elaboración.
